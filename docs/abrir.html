Abre el showroom con INICIAR.cmd

Esta aplicación necesita un servidor local para cargar los planos, las imágenes y la navegación. Abrir index.html como archivo no inicia ese servidor.

  1. Vuelve a la carpeta D:\navegacion interactiva\showroom.
  2. Haz doble clic en INICIAR.cmd.
  3. El navegador se abrirá automáticamente. Deja abierta la ventana del servidor mientras uses el showroom.

Si el servidor ya está encendido, pulsa el botón. Si el navegador indica que no puede conectarse, ejecuta primero INICIAR.cmd.
